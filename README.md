# Loja de pacotes da Central Guará

Este repositório publica os pacotes de catálogo (`.gpf`) que a Central Guará baixa pela loja.

- `indice.json`: lista de pacotes (id, versão, título, tamanho e SHA-256 de cada arquivo).
- `pacotes/`: os arquivos `.gpf`.
- `plugin/`: página do plugin.

Todo o conteúdo de teste é fictício. A Central confere o SHA-256 de cada pacote antes de entregá-lo ao plugin.
